# 🚀 部署到本地电脑/教室一体机

## 快速部署（推荐）

### 方法 1：直接复制整个项目

```bash
# 1. 打包项目
cd ~/openclaw/workspace
tar -czf light-contract.tar.gz light-contract

# 2. 拷贝到 U 盘
# 把 light-contract.tar.gz 拷贝到 U 盘

# 3. 在目标电脑上解压
tar -xzf light-contract.tar.gz
cd light-contract

# 4. 运行一键启动脚本
chmod +x start-deploy.sh
./start-deploy.sh
```

## 解决"正在连接"问题

如果学生端一直显示"正在连接"，是因为没有初始化数据。

### 临时解决方案

打开浏览器控制台（F12），输入：
```javascript
localStorage.setItem('studentId', 'student-001')
location.reload()
```

我会在代码中添加默认数据，稍后更新。

## 教室一体机部署方案

### 方案 A：有网络环境

1. 安装 Node.js
2. 复制项目文件
3. 运行 `./start-deploy.sh`

### 方案 B：无网络环境（离线部署）

1. 在当前电脑准备好所有文件：
```bash
cd ~/openclaw/workspace/light-contract
npm install --production
tar -czf offline-deploy.tar.gz \
  node_modules \
  client \
  teacher-client \
  server \
  package.json \
  start-deploy.sh
```

2. 拷贝到教室电脑，解压后直接运行

## 开机自启动（可选）

### Windows

创建批处理文件 `start.bat`：
```batch
@echo off
cd /d %~dp0
call npm run dev
```

放入启动文件夹：`shell:startup`

### Linux

创建 systemd 服务（见 docs/DEPLOYMENT.md）

## 常见问题

### Q: 端口被占用？
A: 修改 `client/vite.config.ts` 和 `teacher-client/vite.config.ts` 中的端口

### Q: 没有 Node.js？
A: 下载安装：https://nodejs.org/ （选择 LTS 版本）

### Q: 如何重置数据？
A: 清除浏览器 localStorage 或重启 MongoDB
