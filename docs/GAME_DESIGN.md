# 游戏设计文档

## 世界观

### 背景故事

在遥远的地方，有一片沉睡的森林——"精灵森境"。这片森林曾经充满生机与光芒，但因为失去了守护者们的照耀，逐渐陷入了沉睡。

每个学生都是一名"光之守护者"，在初次进入森林时，会与一只沉睡的光之精灵缔结契约。通过完成学习任务、帮助同学、积极参与班级活动，守护者可以获得"星光"，与精灵一起点亮森林，让它恢复往日的生机。

### 核心隐喻

| 游戏元素 | 现实对应 |
|---------|---------|
| 星光 | 学习成就/积分 |
| 亲密度 | 师生关系/情感连接 |
| 精灵进化 | 学生成长 |
| 森林解锁 | 班级集体成就 |
| 星光礼赞 | 同伴认可/鼓励 |

## 角色系统

### 精灵形态

#### 1. 幼苗形态 (Seedling)
- 初始形态
- 外观：小小的发光幼苗
- 解锁条件：初始

#### 2. 开花形态 (Bloom)
- 外观：绽放的花朵，有花瓣环绕
- 解锁条件：亲密度 Lv.5 + 500 星光
- 新能力：短距离飞行

#### 3. 参天形态 (Tree)
- 外观：小型树木，有枝叶
- 解锁条件：亲密度 Lv.10 + 2000 星光
- 新能力：在家园中种植装饰植物

#### 4. 水晶形态 (Crystal)
- 外观：半透明水晶质感
- 解锁条件：亲密度 Lv.15 + 5000 星光
- 新能力：特殊光效、传送能力

#### 5. 神龙形态 (Dragon)
- 外观：小龙形态，有翅膀
- 解锁条件：亲密度 Lv.20 + 10000 星光
- 新能力：自由飞行、特殊互动动作

### 元素属性

| 元素 | 代表色 | 特质 |
|------|-------|------|
| 光 (Light) | 金黄色 | 温暖、希望 |
| 森 (Forest) | 翠绿色 | 生命、成长 |
| 星 (Star) | 紫色 | 神秘、智慧 |
| 风 (Wind) | 天蓝色 | 自由、灵动 |
| 水 (Water) | 湖蓝色 | 温柔、包容 |

## 任务系统

### 任务类型

#### 日常委托 (Daily)
- 持续时间：1 天
- 星光奖励：10-30
- 示例：
  - 今日值日
  - 课堂积极发言
  - 作业全对

#### 周常委托 (Weekly)
- 持续时间：7 天
- 星光奖励：50-100
- 示例：
  - 连续一周按时到校
  - 完成所有作业
  - 帮助同学 3 次

#### 特殊委托 (Special)
- 持续时间：自定义
- 星光奖励：100-500
- 示例：
  - 考试成绩优异
  - 比赛获奖
  - 特殊贡献

### 任务模板

```typescript
interface TaskTemplate {
  title: string
  description: string
  story: string  // 故事背景，增加沉浸感
  starlightReward: number
  intimacyReward: number
  type: 'daily' | 'weekly' | 'special'
}
```

示例：
```
标题：晨间守护者
描述：在今天早上按时到校，开始新一天的冒险
故事：清晨的第一缕阳光洒在森林中，精灵们期待着你的到来...
奖励：15 星光 + 5 亲密度
```

## 赞赏系统

### 星光礼赞

每个学生每天有 3 次机会向同学赠送星光礼赞。

#### 赠送流程
1. 选择要赞赏的同学
2. 选择赞赏原因（可选）
   - 学习帮助
   - 生活关心
   - 团队合作
   - 其他
3. 输入鼓励话语（最多 200 字）
4. 发送

#### 接收效果
- 获得 5 星光
- 精灵做出开心动作
- 显示特效动画

### 敏感词过滤

所有赞赏内容经过敏感词过滤，确保内容健康向上。

| 装饰品 | 价格 | 效果 |
|-------|------|------|
| 小花坛 | 50 星光 | 增加温馨度 |
| 小喷泉 | 100 星光 | 增加活力度 |
| 星光路灯 | 80 星光 | 夜间发光 |
| 长椅 | 60 星光 | 可坐下休息 |
| 风铃 | 40 星光 | 微风吹动有声音 |

### 互动动作

访问同学的家园时可以进行互动：
- 点赞 👍
- 留言 ✍️
- 一起跳舞 💃
- 合影 📸

## 成就系统

### 成就分类

#### 学习类
- 勤快王：连续 7 天完成所有任务
- 学霸之光：单科成绩第一
- 进步之星：进步幅度最大

#### 社交类
- 乐于助人：收到 10 次赞赏
- 人气王：收到 50 次赞赏
- 温暖使者：发送 30 次赞赏

#### 探索类
- 先行者：第一个解锁新区域
- 收藏家：收集所有装饰品
- 探险家：访问 20 个同学家园

### 成就奖励

- 独特徽章展示
- 特殊称号
- 额外星光奖励
- 限定装饰品

## 特殊活动

### 生日庆典

学生生日当天：
- 登录时森林点亮庆祝灯光
- 精灵戴上生日帽
- 系统自动发送 5 次星光礼赞
- 全班同学可以参与庆祝

#### 春节
- 森林换上红色装饰
- 限定精灵装扮

#### 圣诞节
- 森林下雪效果
- 圣诞树装饰
- 特别任务：交换礼物

| 场景 | 风格 | 乐器 |
|------|------|------|

- 赞赏收到：温暖的风铃声
- 按钮点击：柔和的噗噗声
- 升级进化：华丽的升华音效

- 动态粒子特效

- 圆角设计（友好感）
- 半透明背景（轻盈感）
- 柔和阴影（层次感）
- 流畅动画（沉浸感）
