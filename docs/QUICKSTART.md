# 5 分钟快速上手

## 第一步：安装依赖（2 分钟）

```bash
cd ~/openclaw/workspace/light-contract
npm run install:all
```

## 第二步：启动服务（1 分钟）

```bash
npm run dev
```

启动后会看到：
```
🚀 光之契约·精灵森境 后端服务已启动
📡 服务器运行在 http://localhost:4000
📖 API 文档：http://localhost:4000/api

学生端：http://localhost:3000
教师端：http://localhost:3001
```

## 第三步：打开浏览器（1 分钟）

### 学生端体验

1. 访问 http://localhost:3000
2. 完成精灵缔结仪式（3 步）
3. 查看 3D 精灵
4. 浏览森林场景
5. 查看任务列表

### 教师端体验

1. 访问 http://localhost:3001
2. 查看班级总览
3. 发布新任务
4. 查看学生列表

## 第四步：测试功能（1 分钟）

### 测试任务系统
1. 在教师端发布任务
2. 在学生端查看任务
3. 完成任务
4. 查看星光奖励

### 测试赞赏系统
1. 在学生端点击"星光礼赞"
2. 选择同学
3. 输入鼓励话语
4. 发送

### 测试 3D 场景
1. 访问"精灵森林"页面
2. 旋转视角查看场景
3. 观察萤火虫动画

---

## 常见问题

### Q: 页面空白？
A: 检查终端是否有错误信息，尝试清除缓存后重新加载

### Q: 无法连接数据库？
A: 项目支持无数据库模式运行，部分功能会降级

### Q: 端口被占用？
A: 修改对应配置文件中的端口号
