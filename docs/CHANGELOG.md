# 更新日志

## v0.1.0 (2026-03-16) - 初始版本

### ✨ 新增功能

#### 学生端
- ✅ 精灵缔结仪式（3 步引导流程）
- ✅ 5 种元素属性（光、森、星、风、水）
- ✅ 5 种精灵形态（幼苗、开花、参天、水晶、神龙）
- ✅ 3D 精灵展示（Three.js + React Three Fiber）
- ✅ 星光委托任务系统
- ✅ 星光礼赞（同学互赞，每日 3 次）
- ✅ 亲密度系统
- ✅ 个人主页（精灵信息、成就、收到的赞赏）
- ✅ 粒子特效系统
- ✅ 森林 3D 场景（Low Poly 风格）
- ✅ 萤火虫动画
- ✅ 动态光照效果

#### 教师端
- ✅ 班级总览仪表板
- ✅ 森林解锁进度显示
- ✅ 任务管理（创建、编辑、删除）
- ✅ 学生列表查看
- ✅ 班级统计数据

#### 后端
- ✅ Express + Socket.io 服务器
- ✅ MongoDB 数据模型（6 个核心模型）
- ✅ 实时通信（星光更新、赞赏通知）
- ✅ 敏感词过滤
- ✅ 每日赞赏次数限制
- ✅ RESTful API 接口

### 🎨 视觉设计
- ✅ 自定义 Tailwind 主题色（星光紫、森林绿）
- ✅ 渐变背景
- ✅ 圆角卡片设计
- ✅ 流畅动画（Framer Motion）
- ✅ 加载屏幕动画
- ✅ 按钮悬停效果

### 📱 页面路由
- `/` - 学生端首页
- `/forest` - 精灵森林（3D 场景）
- `/tasks` - 星光委托
- `/profile` - 个人主页
- `/bonding` - 精灵缔结仪式
- 教师端：`/`, `/tasks`, `/students`

### 🛠️ 技术栈
- React 18 + TypeScript
- Three.js + React Three Fiber
- Vite 5
- Tailwind CSS 3
- Zustand（状态管理）
- Socket.io（实时通信）
- Express + MongoDB

### 📝 文档
- README.md - 项目简介
- docs/DEVELOPMENT.md - 开发指南
- docs/GAME_DESIGN.md - 游戏设计文档

### 🚀 开发工具
- 一键启动脚本（start.sh）
- Monorepo 结构（npm workspaces）
- 热重载开发环境
